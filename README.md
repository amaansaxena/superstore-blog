# Superstore Sales Analytics with R and Power BI

Static blog for Data Visualization Lab, Assignment 7. No build step.

## Deploy on GitHub Pages
1. Create a repo and push everything in this folder to the `main` branch.
2. Repo Settings > Pages > Source: Deploy from a branch > `main` / root.
3. Wait a minute, then open `https://<username>.github.io/<repo>/`.
4. Replace `YOUR-USERNAME` and `YOUR-REPO` in the footer of `index.html`.

## Before publishing
- Screenshots are already in `assets/` (steps-performed, summary-stats, kpi-cards, dashboard).
- Replace the footer blog link and add MAPE/RMSE in the Holt-Winters section.
